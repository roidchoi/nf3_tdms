# [DEC-005] 비주식성 특수 상품(BC, MF, EW) 수집 제외 필터링 적용

* **상태**: 승인됨 (Decided)
* **작성일**: 2026-06-12
* **관련 Task**: `T-011 스케줄링 변수 중앙화 및 API 개정` 및 마스터 데이터 청정화

---

## 1. 맥락 (Context)
한국투자증권(KIS) 마스터 파일을 수집하여 파싱하는 과정에서, 일반 상장 주식 외에 비주식성 특수 상품인 수익증권(BC), 뮤추얼펀드(MF), ELW(EW) 등이 함께 파싱되어 DB에 적재되는 문제가 있었습니다. 
이로 인해 다음과 같은 부작용이 발생했습니다:
1. **시가총액 및 가격 수정계수 계산 오류**: 주식수가 불분명하거나 수정계수 산출 방식이 일반 주식과 달라 역산 계산 도중 0으로 나누기(Zero Division) 오류 또는 과도한 시총 이상치가 유입될 수 있습니다.
2. **DB 불필요 자원 점유**: 주식 팩터 분석 및 퀀트 투자 분석에 무관한 파생/펀드 자산이 데이터 파이프라인의 노이즈로 작용하여 저장 장치 및 메모리를 낭비합니다.

---

## 2. 의사결정 (Decision)
한국 백엔드(`p2_kdms`)의 KIS 마스터 수집 엔진(`collectors/kis_kr_client.py`)에서 텍스트 라인을 파싱할 때, **그룹코드(Group Code)가 "BC", "MF", "EW"에 해당하는 상품을 수집 대상에서 선제적으로 제외(Filter Out)하도록 변경**합니다.

```python
# tdms_core/p2_kdms/collectors/kis_kr_client.py
# 1) 가변 폭 파싱 내 텍스트 스플릿 처리부
pipe_group = parts[3].strip() if len(parts) > 3 else ""
if pipe_group in ("BC", "MF", "EW"):
    continue

# 2) 고정 폭 바이트 슬라이싱 처리부
group_code = group_code_bytes.decode('cp949', errors='ignore').strip()
if group_code in ("BC", "MF", "EW"):
    continue
```

---

## 3. 결과 (Consequences)
* **데이터 청정도 향상**: 순수 주식(Common Stock) 자산에 대해서만 시가총액 계산 및 팩터 분석이 수행되므로 이상치가 원천 차단됩니다.
* **성능 최적화**: 수집 대상 종목 수가 불필요하게 늘어나는 것을 제어하여 API 조회 속도 및 데이터 수집 주기를 단축시킵니다.
* **비주식 자산 보존 필요성 발생 시 우회 필요**: 차후 수익증권이나 ELW 분석이 필요할 경우에는 마스터 엔진의 이 조건 분기를 해제하거나 별도 채널을 구축해야 합니다.
