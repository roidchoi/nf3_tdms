# Task-009: DB 인계 실행 (폐기 및 통합)

> **상태**: 폐기 (Deprecated)
> **작성일**: 2026-05-12

---

## 폐기 사유

과거 `task-008`이 논리적 동기화(SyncManager)를 구현하고, `task-009`에서 사용자가 수동으로 절차서를 보며 인계를 실행하도록 분리되어 있었습니다.

그러나 대용량 시계열 데이터(TimescaleDB)의 특성상 논리적 동기화가 실패하여 **물리적 동기화(Stop-and-Copy)** 방식으로 전면 전환되었습니다. 
이 과정에서 컨테이너 제어부터 데이터 전송까지 **100% 코드로 자동화된 파이프라인(`db_sync.py`)**을 `task-008`에서 구축하게 됨에 따라, 사람이 수동으로 실행해야 했던 `task-009`의 절차는 불필요해졌습니다.

따라서 기존 `task-009_spec.md` 내용은 폐기되며, 모든 DB 동기화/인계 자동화 스펙은 **`task-008_spec.md`**로 통합 흡수되었습니다.

## 후속 작업
향후 DB 동기화 실행은 `task-008`에서 개발된 자동화 도구를 통해 아래와 같이 단일 명령어로 수행됩니다.

```bash
# 예시: 서버의 usdms 데이터를 개발PC로 물리 복제 (Pull)
conda run -n tdms_p1_env python -m p1_shared.ops.db_sync --db usdms --direction pull
```
